# Flowdesk

Веб-сайт для управления задачами команды — общая Kanban-доска с совместной
работой в реальном времени. Next.js 14 (App Router) + TypeScript + Tailwind
CSS + Supabase (Postgres, Auth, Realtime, Storage).

## Возможности

- Вход через **Google** — профиль (имя, фамилия, email, фото, роль, отдел) создаётся автоматически при первом входе.
- Одна общая доска: Бэклог → К выполнению → В работе → На проверке → Выполнено. Drag & drop.
- **Realtime**: создание задачи, перемещение карточки, смена срока, комментарий, назначение исполнителя, удаление — видно у всех сразу, без обновления страницы.
- **Presence**: 🟢 «онлайн сейчас», «Х сейчас редактирует эту задачу», «Y печатает комментарий…».
- Dashboard-полоса вверху: всего задач / в работе / на проверке / просрочено / завершено.
- Поиск по задачам, сотрудникам и комментариям. Фильтры по исполнителю, приоритету, просроченности.
- Комментарии как чат: файлы, изображения, @упоминания, эмодзи.
- Уведомления: назначение задачи, новый комментарий, смена статуса, приближение дедлайна (по расписанию через pg_cron).
- Роли Administrator / Manager / Employee / Viewer с проверкой прав на уровне базы данных (Row Level Security), а не только в интерфейсе.

## Структура проекта

```
supabase/schema.sql          вся база данных: таблицы, роли, RLS, триггеры, realtime, pg_cron
src/lib/supabase/            клиенты Supabase (браузер / сервер / middleware)
src/lib/database.types.ts    TypeScript-типы по схеме БД
src/hooks/usePresence.ts     realtime presence (онлайн / редактирует / печатает)
src/hooks/useCurrentUser.ts  текущий профиль
src/components/              KanbanBoard, TaskPanel, QuickAddModal, AppShell, EmployeesGrid
src/app/                     страницы (Next.js App Router)
DEPLOYMENT.md                пошаговое развёртывание: Supabase → Google OAuth → Vercel
```

## Быстрый старт

См. **`DEPLOYMENT.md`** — весь путь от нуля до рабочей ссылки
`https://your-app.vercel.app`.

Локальная разработка:
```bash
npm install
cp .env.local.example .env.local
npm run dev
```

## Важно

Код не был собран (`npm run build`) в среде, где он написан — там нет доступа
в интернет и невозможно выполнить `npm install`. Логика и синтаксис проверены
вручную, в том числе точечной проверкой TypeScript-компилятором. Если при
первом деплое на Vercel возникнет ошибка сборки — пришлите её текст, поправлю быстро.
